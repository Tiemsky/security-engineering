# Completion criteria (applies to every task)
A task is complete only when: (1) every acceptance criterion of the active skill is met or explicitly waived by the user;
(2) tests added/updated and executed, with real output reported; (3) no secrets or sensitive data introduced;
(4) the Reviewer (independent context) has no open High/Critical finding; (5) the environment profile and assessment matrix are present, PASS rows carry evidence, and missing evidence is reported as not tested, never as a pass; (6) the final report uses the skill's report format and
separates **Implemented / Tested / Unverified**.
