# Generic runtime contract (for new frameworks — see skill `framework-adapter-development`)
An adapter must: (1) resolve client IP only through trusted proxies (IPv4/IPv6, /64 aggregation); (2) emit `http_access` with the route **template**; (3) apply `policies/redaction.yaml` before any sink; (4) never let sink/store failures alter the response (fail-open, except credential limiters); (5) feed the deterministic engine and persist decisions + outcomes with idempotency keys; (6) enforce only active, unexpired scopes; (7) pass `tests/fixtures/scenarios/*.json` with results identical to Laravel and NestJS (`tests/integration/compare.py`).
Engine semantics (reference: `laravel/src/DecisionEngine.php`, `nestjs/src/decision-engine.ts`): window counters per rule+group → threshold/min_distinct → exceptions (allowlist, shared-IP ⇒ manual_review) → evidence minimum → approval gates → mode (observe⇒would_act, alert⇒alert, enforce⇒act+TTL) → idempotency key `rule:version:scope_kind:scope_value:window_start` → outcome (applied | skipped_observe_only | skipped_duplicate | failed | expired | rolled_back).
